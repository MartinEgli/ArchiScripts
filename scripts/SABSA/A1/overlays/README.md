# SABSA A1 Overlay Scripts

This folder contains A1 overlay generators and overlay maintenance scripts.

- `Generate_SABSA_A1_Overlay_Type_Model_Views.ajs` generates the overlay overview and type model views.
- `Generate_SABSA_A1_Overlay_Template_Library_Views.ajs` generates overlay template relationship and library views.
- `Apply_SABSA_A1_Overlay_Stereotype_From_Metamodel.ajs` applies one generated overlay stereotype to a selected element.
- `Cleanup_SABSA_A1_Field_Metadata_From_Explicit_Elements.ajs` removes old verbose field metadata from explicit/generated overlay elements.
