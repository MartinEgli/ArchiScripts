# SABSA A1 Core Scripts

This folder contains shared implementation files used by focused SABSA A1 entry points.

- `Generate_SABSA_A1_Field_Catalogue_Core.ajs` contains the common field-catalogue generator implementation.
- `Run_SABSA_A1_Field_Catalogue_Mode.ajs` is the shared runner loaded by the focused field-catalogue entry points after they set the desired mode and dialog metadata.

These files are not intended as normal user-facing scripts. Run the focused scripts in the parent A1 folder instead.
