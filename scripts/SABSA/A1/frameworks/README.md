# SABSA A1 Framework Scripts

This folder contains A1 framework and diagram-style generators.

- `Generate_SABSA_A1_Generic_Risk_Management_Model_View.ajs` generates the generic risk management model view.
- `Generate_SABSA_A1_Risk_Strategy_Framework_View.ajs` generates the risk strategy framework view.
- `Generate_SABSA_A1_Attribute_Profile_Framework_View.ajs` generates the attribute profile framework view.
- `Generate_SABSA_A1_Assurance_Framework_View.ajs` generates the assurance framework view.
- `Generate_SABSA_A1_Risk_Feedback_Control_System_View.ajs` generates the risk management feedback control system view.
