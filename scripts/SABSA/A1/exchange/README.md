# SABSA A1 Exchange Scripts

This folder contains A1 JSON and exchange-schema import/mapping generators.

- `Generate_SABSA_A1_Exchange_Schema_Type_Relationship_Mapping_Views.ajs` generates type and relationship mapping views from the generic exchange schema.
- `Generate_SABSA_A1_Q003_Q004_JSON_Extracted_Model_Views.ajs` imports the Q003/Q004 JSON extract and generated views.
