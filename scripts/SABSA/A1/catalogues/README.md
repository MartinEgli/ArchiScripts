# SABSA A1 Catalogue Scripts

This folder contains A1 field-catalogue and metamodel catalogue generators.

- `Generate_SABSA_A1_Field_Catalogue_Document_Parts_View.ajs` generates the document-parts view.
- `Generate_SABSA_A1_Field_Catalogue_Table_Index_View.ajs` generates the table-index view.
- `Generate_SABSA_A1_Metamodel_Architecture_Views.ajs` generates metamodel architecture, core type, FK, relationship and viewpoint views.

The entry points load the shared implementation from `../core/Run_SABSA_A1_Field_Catalogue_Mode.ajs`.
