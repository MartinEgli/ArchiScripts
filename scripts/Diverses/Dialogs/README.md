# Dialog Basics

Dieser Ordner enthaelt einfache Beispiele fuer den Umgang mit Dialogen in jArchi.

Die Beispiele verwenden:

- `../../lib/logging/Logger.js`
- `../../lib/ui/DialogHelpers.js`

## Inhalt

- `Info_Dialog_Basic.ajs`
  einfacher Info-Dialog mit Logging
- `Confirm_Dialog_Basic.ajs`
  Bestaetigungsdialog mit Logging des Ergebnisses
- `Prompt_Text_Basic.ajs`
  einfache Texteingabe
- `Prompt_Selection_Basic.ajs`
  kleine Auswahlliste
- `File_Dialogs_Basic.ajs`
  Datei- und Verzeichnisdialoge
