# Logging Basics

Dieser Ordner enthaelt einfache Logging-Beispiele fuer jArchi-Skripte.

Die Beispiele verwenden den gemeinsamen Logger unter:

- `../../lib/logging/Logger.js`

## Inhalt

- `Console_Basic_Output.ajs`
  einfache Konsolenausgaben
- `Dialog_Basic_Output.ajs`
  Konsolen- und Dialogausgabe
- `Structured_Logging_Example.ajs`
  strukturierte Logs ueber den zentralen Logger

## Zweck

Die Skripte sind als Startpunkt fuer eigene Logging-Konventionen gedacht und nutzen bereits die gemeinsame Logging-Utility.
