# NIST Data

Dieser Ordner enthaelt lokal abgeleitete Datensaetze fuer die NIST-View-Generierung.

## Quelle

- `nist-sp-800-53r5-controls.json`
  Abgeleitet aus [NIST.SP.800-53r5.pdf](/c:/Reops/Archi/docs/Standards/NIST.SP.800-53r5.pdf)

## Zweck

Der Datensatz erlaubt es den jArchi-Skripten, in einem leeren Modell echte NIST-Control-Objectives und Child-Elemente aufzubauen, auch wenn zuvor nur die Familienstruktur importiert wurde.
